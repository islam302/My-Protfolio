# Islam Badran — portfolio

Static, multi-page portfolio for Islam Badran, full-stack software engineer at ETQAN.
Plain HTML/CSS/JS generated by a ~100-line Node build — **no dependencies, no framework**.

## Run it

```bash
npm run dev       # build + serve on http://localhost:4321, rebuilds on save (refresh the browser)
npm run build     # → dist/
npm run check     # broken links/assets, one <h1> per page, titles/descriptions unique, img alt
npm run preview   # build once and serve dist/
```

Set the production origin before deploying (used for canonical URLs, Open Graph and `sitemap.xml`):

```bash
SITE_URL=https://your-domain.com npm run build
```

Production runs on a Hetzner server behind nginx (Docker Compose) — see `infrastructure/deployment/DEPLOYMENT.md`.
The web image passes `SITE_URL` as a build argument.

## Where things live

```
src/
  data/site.js          Name, role, contact links, nav — change facts here once
  data/projects.js      Every project: copy, theme colours, images. Drives the home reel,
                        /work/, each /work/<slug>/ page, the sitemap and structured data
  pages/*.js            One module per route; default export returns a page object (or an array)
  templates/layout.js   <head> (SEO, Open Graph, JSON-LD), header nav, footer. Page contract documented at the top
  templates/partials.js Breadcrumbs, CTA band, project links shared across pages
  lib/images.js         Reads WebP sizes so every <img> gets width/height
  lib/html.js           Escaping `html` tagged template
  lib/seo.js            URL + JSON-LD helpers
  styles/site.css       Design tokens + shared components; page CSS in its own file
  scripts/*.js          Browser JS (ES modules), copied to /js/
public/                 Copied to dist/ as-is
  images/hero/          Hero plate, cut-out, laptop plate, lanyard badge
  images/projects/<slug>/   Screenshots + logo per project (`*-800.webp` = card size)
  media/hero-dive.mp4   Hero → laptop transition clip
  fonts/                Inter Tight, Anton, Caveat Brush (woff2)
scripts/                build.mjs, serve.mjs, check.mjs
tools/brand/            Recolour green → ETQAN blue (images: recolor.py, video: recolor-video.swift)
_archive/               (local only, not in the repo) old single-file site and original hero assets
```

## Brand colours

The site uses the ETQAN identity: navy `#141936`, deep navy `#0d0f26`, blue `#245593 → #3570a2 → #5fb0d6`,
light `#f5f7fa`. All colours are tokens at the top of `src/styles/site.css` (`--navy-*`, `--blue-*`, `--sky`).
The hero photos and the dive video were shot on green and recoloured with `tools/brand/`:

```bash
python3 tools/brand/recolor.py in.webp out.webp            # needs Pillow
swift tools/brand/recolor-video.swift in.mp4 out.mp4       # macOS only, uses AVFoundation
```

## Adding a project

1. Put screenshots in `public/images/projects/<slug>/` (`cover.webp` ≈1600px wide, plus an 800px `cover-800.webp` for cards, and `logo.webp`).
2. Add an entry to `src/data/projects.js` (copy an existing one).
3. `npm run build && npm run check`. The home reel, /work/, the case-study page and the sitemap update automatically.
